# Appareils réalistes du Studio (NEXORA #100)

Modèles GLB générés par NEXORA à partir du code de **react-3d-mockups** 0.2.0
(https://github.com/area-is/react-3d-mockups), dont chaque appareil est construit en three.js d'après ses
dimensions réelles, sans fichier 3D tiers. Export : scène React Three Fiber rendue dans Chromium, puis
GLTFExporter de three.js ; la surface d'écran est remplacée par un maillage `NX_SCREEN` à coordonnées de
texture normalisées (reconnu par `screenMesh()` du Studio).
